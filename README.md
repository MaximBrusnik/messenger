Мессенджер с AI-ассистентом
------------
Стек
---
Слой	Технология
Бэкенд	Go 1.22+, PostgreSQL, Nats, Redis, gRPC, Microservices, Gin, GORM,

Фронтенд	React (Vite 8 + Rolldown), TypeScript

Android	Capacitor (WebView APK)

AI	Gemini 2.5 Flash 

возможности
---
1) Регистрация/вход (JWT), профиль, аватар, настройки приватности
2) Личные чаты с текстом, файлами, реакциями, пересылками сообщений, ответами сообщений
3) Редактирование и удаление сообщений/чатов
4) Уведомления через WebSocket (онлайн-статус, новые сообщения, прочтения)
5) Двойные галочки прочтения
6) AI-ассистент на Gemini 2.5 Flash
7) Общая для всех юзеров музыка (загрузка, плеер, стриминг, скачивание, лимит 1 ГБ)
8) Модерация музыки администратором (одобрить/отклонить)
9) Звук и браузерные уведомления о новых сообщениях
10) Firebase Push уведомления для андроид приложения
