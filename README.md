Мессенджер с AI-ассистентом
------------
Стек
---
Слой	Технология
Бэкенд	Go 1.22+, Gin, GORM, PostgreSQL (Docker)

Фронтенд	React (Vite 8 + Rolldown), TypeScript

Android	Capacitor (WebView APK)

AI	Gemini 2.5 Flash (Google AI Studio)

возможности
---
1) Регистрация/вход (JWT), профиль, аватар, настройки приватности
2) Личные чаты с текстом, файлами, реакциями, @упоминаниями, ссылками
3) Редактирование и удаление сообщений/чатов
4) Уведомления через WebSocket (онлайн-статус, новые сообщения, прочтения)
5) Двойные галочки прочтения (✓ → ✓✓)
6) AI-ассистент на Gemini 2.5 Flash
7) Общая для всех юзеров музыка (загрузка, плеер, стриминг, скачивание, лимит 1 ГБ)
8) Модерация музыки администратором (одобрить/отклонить)
9) Звук и браузерные уведомления о новых сообщениях

билд:
----
в папке backend есть скрипт-сборщик: ./build.bat (для винды. для линухов хуй знает поможет ли это) создает бинарники под линукс и виндовс архитектуру 

Запуск на винде 
./messenger.exe 

Запуск на линукс 
./messenger-linux 


Есть докер, докер-композ, но лучше всего запускать только postgres в докере (было сделано из-за того что в докере запустить бэк+фронт на сервере с 1 ГБ оперативы хуевая идея). Все остальное в бинарнике запускается
